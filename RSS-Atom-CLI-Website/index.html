RSS-Atom-CLI

A dependency-free RSS and Atom reader for the terminal.

What this is

I wrote this to read feeds without opening a browser or installing anything. I hand it one or more feed URLs or local feed files, and it prints the newest items with dates and links.

It reads two formats. RSS 2.0 comes in through the channel and item tags in rss_tool.py. Atom comes in through the namespaced entry tags, and I take the first link with no rel or with rel alternate, because that is the article link and not the feed machinery.

One bad feed does not kill a run. I catch errors per feed and keep going, and the run only exits non-zero when every feed failed.

The --open rule

The module docstring promised an --open flag for a long time and the code did not have it. It exists now. It prints one item link on its own line after the listing, like this from my local fixture run:

open[2]: https://example.com/2

It does not launch a browser. That is deliberate. I use this over SSH and in scripts, where there may be no browser at all. If the number is out of range it says how many items the feed has instead of failing.

Commands, as printed in the README

python3 rss_tool.py https://example.com/feed.xml
python3 rss_tool.py feed1.xml feed2.xml --limit 5
python3 rss_tool.py https://example.com/feed.xml --open 2

Dates, and the fallback I kept

Atom dates parse with fromisoformat after I swap a trailing Z for +00:00. RSS dates use the RFC 822 shape, which fromisoformat cannot read, so I print the first 16 characters. That slice is the weekday and the date, and part of a date beats no date.
