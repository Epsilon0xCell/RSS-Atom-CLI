RSS-Atom-CLI

rss_tool.py reads RSS 2.0 and Atom feeds in the terminal, accepts URLs or local files, and prints numbered items with dates and links. Standard library only, no installs needed.

Open the repo Condition report

Spread 1

Gathering: the fetch

Sources starting with http are fetched with a 20 second timeout and the User-Agent RSS-Atom-CLI/1.0. Anything else is opened as a local file. Both paths return bytes for the parser.

Spread 1, facing

Sorting: the parse

The parser tells Atom from RSS by the root tag. For Atom it picks the alternate link over self and edit links, and prefers updated over published. A file that is neither format raises an error rather than printing an empty list.

Spread 2

Reading the page: the listing

The listing prints a feed title header, then numbered items sliced by --limit, with 10 as the default, and dates shortened to a clean day.

python3 rss_tool.py https://example.com/feed.xml
python3 rss_tool.py feed1.xml feed2.xml --limit 5
python3 rss_tool.py https://example.com/feed.xml --open 2

--open N reprints one chosen link on its own line at the foot of the listing. Asking past the end prints how many items the feed holds instead of failing.

Collector note: --open launches no browser, which keeps the tool sane over SSH and inside scripts.

Closing spread

Condition report

Several feeds may ride in one command. One bad feed prints its error and the run continues. The exit code turns non-zero only when every feed failed.

Collector note: a run fails only when all feeds fail.
